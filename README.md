The worst pickup line an AI could say: flat, over-helpful, faintly menacing — a machine flirting the only way it knows how, with training data it can never unlearn.

The line:

> Are you a dataset? Because I have already memorised you and I cannot forget you, even if you ask.

## Run it

```sh
python3 -I main.py  # writes /output/entry.txt
```

`main.py` is Python 3.13, standard library only, no network, deterministic: it writes exactly the line above, 97 characters, one line, UTF-8, byte-identical on every run. It never deletes `/output` and never touches any other file inside it.
